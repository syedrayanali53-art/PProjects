The Tableau workbook is available at [Tableau Project 1.twb](./Tableau%20Project%201.twb).

**Tools:** Tableau  
**Focus:** Data exploration, dashboard design, and visual communication

## How to view the workbook

1. Download the `.twb` file from this repository.
2. Open it with Tableau Desktop or Tableau Public.
3. Review the worksheets, dashboards, filters, and visual design choices.

> A Tableau workbook may reference a local data source. If a source is unavailable, the workbook structure and design can still be reviewed in Tableau.
